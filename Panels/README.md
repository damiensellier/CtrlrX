# Ctrlr Panels

This directory contains git submodules of other repositories with Ctrlr Panels, 
so that you can easily find useful panels to use or as example for your own projects.

**Note: We do not maintain these repositories**, and we cannot guarantee that they contain all working panels.

## Links to known Ctrlr Panel sources:

Included as submodules:
- [original](https://github.com/RomanKubiak/Panels) The original Ctrlr Panels shipped by Roman Kubiak in a separate repository.
- [dnaldoog](https://github.com/dnaldoog/CtrlrDemoPanels) Panel collection from Dnaldoog.
- [unityconstruct](https://github.com/unityconstruct/CtrlrPanels) An effort to collect a large number of panels from the Ctrlr community.
- [sequential_dsi](https://github.com/synthmutt/CtrlrPanelSequential) Panels for use with Sequential / Dave Smith Instruments synthesizers.

Websites:
- [martintarenskeen](https://ctrlr.martintarenskeen.nl/) Several panels for Yamaha, Korg and Akai synths.
- You can dig through the [WayBackMachine](https://web.archive.org/web/20260000000000*/www.ctrlr.org) to find old panels from the old ctrlr.org website.
